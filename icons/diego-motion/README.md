# Diego web motion assets

Approved poses copied from `mockups/diego-motion-v2/assets` for the web app. Each scene has four transparent 640 × 640 WebP frames. Do not use the ignored mockup directory as a production dependency.

- Onboarding: 18 scenes, selected in `js/ui/onboarding-motion.js`.
- Routine/home portraits: `portrait`, with a five-second blink cycle.
- Routine completion: `complete`, with a restrained celebration.
- Character preference: `profile.onboarding.character`; Profile and onboarding share this setting.
- Reduced motion: shows a single still pose.

Native mobile assets and screens are separate and were not updated.
